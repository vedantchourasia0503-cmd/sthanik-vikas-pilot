# Sthanik Vikas AI

Build a full-stack, mobile-responsive web application named “Sthanik Vikas AI (स्थानीय विकास AI) — Micro-Business Co-Pilot” for Indian micro-entrepreneurs, street vendors, and small business owners. Include English/Hindi/Regional language selector; accessible clean financial UI. Build an interactive voice-first business entry flow with a prominent “🎤 Tap to Speak Business Details” floating button using browser Web Speech API / webkitSpeechRecognition with English and Hindi (hi-IN), plus direct form inputs for entrepreneur name, business type, average daily income/expense, category/social group, and location/city. Voice input should auto-populate where feasible and gracefully explain unsupported browsers. Create a financial assessment and micro-ledger dashboard with calculated net monthly income and profit margin, health status (Healthy/Moderate/Critical), and visual micro-credit eligibility gauge. Add a government scheme matcher with cards for PM SVANidhi, PM Vishwakarma, Mudra Loans, PMEGP, each showing loan limit, subsidy %, benefits, and Apply/Eligibility accordion. Add “📄 Download Bank-Ready Financial Statement” which creates a structured downloadable PDF summary of ledger and scheme recommendations. Use slate-blue buttons, emerald profit stats, warm amber accents, full responsive design. Enable backend/cloud only if needed; make a polished working prototype with sensible defaults and calculations.
